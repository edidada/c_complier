## 0. 缺陷修复设计（阶段 0，最高优先级）

### D1：变量重复定义误报 + SIGILL 崩溃（`interCode.cpp` 的 `Body_Generate`）

**现状问题链**（已确认）：
```
Body_Generate(node, table)
 ├─ STATEMENT 分支：Def_Stmt → 递归每个 child（Some_Stmt 链）
 │    └─ Def_Var 分支(1293行)：取 mod_node->getNextSibling()=DefList，对每个 DefList 递归 Body_Generate
 │         └─ Def_Single_Var 分支(1308行)：又对 node->getFirstChild()(Var) 处理
 │              └─ Var_ONLY 分支(1366行)：Block_Single_Vardef(1391行)：
 │                   ① findSymbolLocally(var_name) 命中已有符号 → 误报重复定义
 │                   ② addSymbol(var) → 同一变量被加两次
```
**后果**：test1.c 中 `int a;` 的符号被加入两次，第二次 `findSymbolLocally` 命中即误报；随后空指针/非法访问导致 SIGILL。

**修复设计（两趟式声明处理）**：
1. **趟 1——声明收集**：新增 `collectDeclarations(AbstractAstNode* defListNode, SymbolTable* table)`，只负责把 `DefList → Def_Single_Var → Var_ONLY → Block_Single_Vardef` 链中每个变量名加入符号表（含数组 `Block_Array_Vardef` 的维度、指针 `Var_POINT` 的类型），**不做任何代码生成**。变量重复定义在此统一检测并报错。
2. **趟 2——代码生成**：`Body_Generate` 只负责生成赋值/表达式/控制流代码，**不再触碰符号表插入**，声明语句（`Def_Stmt`）仅生成变量在栈上的空间分配（移动 offset）。
3. **路径唯一化**：删除 `Def_Var` 分支中对 `DefList` 的递归生成调用（1293-1307 行的生成部分），改为：`Def_Var` 只调用 `collectDeclarations`；`DefList` 不再被 `Body_Generate` 递归。
4. **空指针保护**：所有 `getFirstChild()`/`getNextSibling()` 返回值在使用前判空；对未知 `content` 分支打印警告并跳过，绝不 `exit`（崩溃恢复原则：语义错误只记录、不终止进程）。

**验收**：test1~6 全部编译通过、运行输出正确；无重复定义误报；无 SIGILL。

## 1. 词法分析（`scanner.l`）

### 1.1 Token 全集（对照现有实现核对）

| 类别 | Token | 词素 |
|---|---|---|
| 关键字 | `VOID INT RETURN IF ELSE THEN WHILE FOR BREAK CONTINUE PRINTF SCANF` | void int return if else then while for break continue printf scanf |
| 标识符 | `IDENTIFIER` | `[a-zA-Z_][a-zA-Z0-9_]*`（属性：`yylval.str=strdup(yytext)`） |
| 整型常量 | `CONST` | `[1-9][0-9]* \| 0`（属性：数值；**注意 scanner.l 当前把 CONST 当字符串返回，需核对**） |
| 算术 | `ADD SUB MUL DIV MOD POW` | `+ - * / % ^` |
| 关系 | `EQ_OP NE_OP GT_OP LT_OP GE_OP LE_OP` | `== != > < >= <=` |
| 逻辑 | `AND OR NOT`（`SINGLAND` 为 `&&` 单字符版，需核对） | `&& \|\| !` |
| 赋值 | `ASSIGN_OP` | `=` |
| 分隔 | `COMMA SEMI S_QUO D_QUO` | `, ; ' "` |
| 括号 | `( ) [ ] { }` | 直接返回单字符 |
| 结束 | `EOL` | 行尾/文件尾 |

### 1.2 注释与空白
- 行注释 `//...`、块注释 `/* ... */`（支持嵌套与否在实现时明确并测试）
- 空白/换行：跳过，维护 `line` 计数（**新增** `int yylineno` 用于错误定位）

### 1.3 词法错误（[待实现] M1-3）
- 非法字符：`[^ ...]` 落入 error 规则，输出 `[行号] 非法字符: xx`
- 未闭合注释：遇到 EOF 仍在块注释中 → 报错
- 整型溢出：超过 `INT_MAX` 报错（或按 long 处理，实验可放宽）

### 1.4 输出格式（对照《词法分析器上机要求》）
```
单词      词素     属性
VOID      void
IDENTIFIER a       <指向符号表项/名称>
CONST     3        3
```
实现为独立模式开关（如 `--lex-only`），便于词法部分单独演示。

## 2. 语法分析（`parser.y`）

### 2.1 文法框架（现有 `%type` 已含）

```
Program       : FuncList
Func          : Descriptor IDENTIFIER '(' ParamList ')' Block
Descriptor    : VOID | INT | ...
Block         : '{' BlockList '}'
BlockList     : BlockItem*
BlockItem     : Vardef | Stmt
Vardef        : INT VarList ';'          // 声明
VarList       : VarItem (',' VarItem)*   // 支持 int a, b[4], *p;
Stmt          : ExpStmt | IfStmt | WhileStmt | ForStmt
              | PrintStmt | ScanStmt | ReturnStmt
              | BreakStmt | ContinueStmt | Block
ExpStmt       : Exp ';' | ';'
IfStmt        : IF '(' Exp ')' Stmt (ELSE Stmt)?   // 悬空 else: %prec LOWER_THAN_ELSE
WhileStmt     : WHILE '(' Exp ')' Stmt
ForStmt       : FOR '(' Exp? ';' Exp? ';' Exp? ')' Stmt
Exp           : ...（含赋值、算术、关系、逻辑，优先级见 §2.2）
```

### 2.2 优先级与结合性（现有声明核对）

```
优先级从低到高：
  ASSIGN_OP(=)         右结合
  OR(||)  AND(&&)
  EQ_OP NE_OP
  GT_OP LT_OP GE_OP LE_OP
  ADD SUB
  MUL DIV MOD
  POW(^)               左结合（C 语言 ^ 为异或，实验按幂运算处理，文档注明）
  NOT(!)               右结合
  一元负号（UMINUS）
  ( ) [ ]              括号/下标
```

### 2.3 AST 构建动作
- 每个归约规则在 action 中创建 `AbstractAstNode`，按结构挂接 `first_child`/`next_sibling`
- 表达式节点 `content` 存运算符（如 `"+"`），叶子存操作数
- `yyerror` 记录错误并带行列号；**新增 `%define parse.error verbose`** 提高错误可读性

### 2.4 语法错误恢复（[待实现] M2-4）
- 设置错误同步点：在 `;` `}` `)` 等 token 上 `error` 规则，遇到语法错误后丢弃 token 直到同步点，继续分析
- 单个错误不中断整个编译（`YYERROR` 恢复而非退出）
- 错误计数：每个文件最多报 N 个语法错误（如 20）后终止

### 2.5 文法覆盖核对清单（对照实验要求）
- [x] 声明：`int a; int a=1; int a[4]; int *p; int a,b;`
- [x] 赋值：`a = 表达式`
- [x] 循环：`while`、`for`（含 `for(;;)`）
- [x] 判断：`if` / `if-else`
- [x] 输入输出：`printf`/`scanf`（或 `print_int`）
- [x] 注释、复合语句、break/continue、return
- [x] 函数定义与调用（加分项，现有 `Func` 规则基础）

## 4. 符号表（`symbol_table/`）

### 4.1 Symbol
```cpp
class Symbol {
    std::string name;
    SymbolType type;        // integer / var(数组、指针)/ func / 待扩展: struct
    int sym_offset;         // 栈帧内偏移（字节）
    bool isArray;  int arraySize;  // 数组
    bool isPointer; int ptrDepth;  // 指针深度（多重指针）
    bool isFunction;
    // FuncSymbol 单独类：args、returnType
};
```

### 4.2 SymbolTable（作用域）
```cpp
class SymbolTable {
    bool isGlobal;                 // 全局表（根）
    SymbolTable* parent;           // 父作用域
    std::vector<SymbolTable*> children;
    Symbol* findSymbol(name);        // 自底向上
    Symbol* findSymbolLocally(name); // 仅本层（重复定义检测用）
    void addSymbol(Symbol*);         // 重复定义在此统一报错（D1 修复后只被 collectDeclarations 调用）
    int getOffset(); void setOffset(int);  // 栈帧偏移分配
};
```

### 4.3 D1 修复后的调用约束（关键）
- **符号插入只允许发生一次**：每个变量在 `collectDeclarations`（趟 1）插入
- `Body_Generate` / 代码生成 **不再调用 addSymbol**
- `findSymbolLocally` 重复定义检测逻辑保留，但仅趟 1 使用
- 函数作用域：`main` 等每个函数独立 `SymbolTable`，参数进入函数作用域

## 5. 语义分析：类型检查（[待实现] 新增 `semantic/` 模块）

### 5.1 类型系统
```
Type ::= int | int* | int[] | void | struct-name | function(ret, args...)
（数组/指针维度信息由 AST 提供）
```

### 5.2 检查规则
| 规则 | 说明 | 错误示例 |
|---|---|---|
| R1 变量已声明 | 标识符必须先声明再使用 | `x = 1;`（x 未声明） |
| R2 禁止重复声明 | 同作用域同名变量 | `int a; int a;` |
| R3 赋值类型兼容 | 右值类型可赋给左值（int→int；指针类型匹配；数组名退化） | `int a; int *p; p = a;` |
| R4 算术运算数 | `+ - * / % ^` 操作数须为 int | `int *p; p + 1.0` |
| R5 取模/除法非零 | 除零检查（可在优化期做常量除零检测） | `a / 0`（常量） |
| R6 下标 | 下标操作符 `[ ]` 左操作数为数组/指针，下标为 int | `int a; a[0];` |
| R7 指针运算 | `&x` 要求左值；`*p` 要求指针；指针 + int 合法 | `&3; *a;`（a 非指针） |
| R8 函数调用 | 实参个数与形参一致、类型兼容；返回类型匹配 | `void f(); f(1);` |
| R9 return | 函数返回类型与 return 表达式类型一致（void 函数不返回值） | `int f(){ return; }` |
| R10 条件表达式 | if/while/for 条件为 int（或可转 int） | `if(p) ...`（p 为指针，C 语义允许，按实验放宽为 int） |

### 5.3 实现方式
- 独立一遍：在 AST 上做**符号收集 + 类型推导 + 规则检查**，与代码生成解耦
- 输出：错误列表 `vector<SemanticError>{line, msg, kind}`，全部收集后统一打印
- 数据结构：`Symbol* lookup(name)` 复用符号表；表达式类型用 `SymbolType` 或新的 `TypeInfo{kind, ptrDepth, arraySize}`
- 入口：`void typeCheck(AbstractAstNode* root, SymbolTable* global)`

## 6. 中间代码（`intermidiate_code/`）

### 6.1 四元式结构（现有 `QuadItem` 核对）
```
格式： (result, op, arg1, arg2)
result/arg1/arg2 为 Arg 联合体（int 常量 或 Symbol* 变量）
OpType：addtion substract multiply divide mod power assign
        logic_and logic_or logic_not uminus
        label JUMP JUMP_LT/LE/GT/GE/EQ/NE
        RETURN_OP PRINT SCAN PARAM CALL
```

### 6.2 生成规则（现有 `Body_Generate` / `Exp_Stmt_Generate` 核对 + 修复）
| 语法 | 中间代码 |
|---|---|
| 常量/变量 | 加载到临时变量 `t = const / t = var` |
| `a op b` | `t1 = a; t2 = b; t = t1 op t2` |
| 赋值 `a = e` | `t = e; a = t` |
| `if (c) S1 else S2` | `c 求值 → JUMP_xx L1; ...; JUMP L2; L1: S1; L2: S2`（回填） |
| `while(c) S` | `L1: c; JUMP_xx L2; S; JUMP L1; L2:` |
| `for(a;c;s) S` | `a; L1: c; JUMP_xx L2; S; s; JUMP L1; L2:` |
| `&&` / `\|\|` 短路 | 真/假值链回填（现有 trueList/falseList 机制） |
| `print(e)` | `PRINT t` |
| `return e` / `return;` | `RETURN t` / `RETURN` |
| `scanf(x)` | `SCAN x` |
| 数组读写 `a[i]` / 指针 `*p` `&a` | 符号名形式 `a[i] := t` / `b := a[i]` / `*p := t`（汇编阶段字符串解析） |
| 函数调用 `f(a,b)` | `PARAM a; PARAM b; CALL f, 2` |
| `a[i]` / `*p` | 地址计算 + 访存（新增指令或复用 assign） |
| 函数调用 | `PARAM a1; PARAM a2; CALL f, n;`（[待实现] 扩展 OpType） |
| return | `RETURN_OP t` |

### 6.3 [已实现] 新增 OpType
```
PARAM, CALL（函数调用，T4 已生成四元式，调用约定在 7.1）
RETURN_OP / SCAN：枚举原有，T4 补全生成与打印
ADDR（&）/ DEREF（*）/ INDEX（[]）：无需三地址指令，
  采用符号名形式（&a / *p / a[i]）承载，汇编阶段字符串解析
```

### 6.4 修复 D1/D2 落点（与 §0 对应）
- `collectDeclarations` 完成符号收集后，`Body_Generate` 对 `Def_Stmt` 仅生成栈空间分配
- 跳转/回填逻辑不动，仅对声明路径做重构

## 7. 汇编生成（`asm/`）

### 7.1 寄存器分配（现有 `AsmGenerate` 核对）
```
可用通用寄存器：eax, ebx, ecx, edx
分配策略：临时变量按需申请寄存器，用完 releaseRegister 回收
栈帧：ebp 基址 + 负偏移访问局部变量（变量 sym_offset 决定）
被调用者保存：ebx（现有代码已 push ebx）
```

### 7.2 四元式 → 汇编映射
| 中间代码 | 汇编 |
|---|---|
| `t = c`（常量） | `mov reg, c` |
| `t = v`（变量） | `mov reg, [ebp - off]` |
| `t = t1 + t2` | `mov eax, t1; mov ebx, t2; add eax, ebx; mov t, eax` |
| `t = t1 - t2` | 同上 `sub` |
| `t = t1 * t2` | `imul` |
| `t = t1 / t2` | `cdq; idiv ebx`（余数在 edx） |
| `t = t1 % t2` | `idiv` 后取 edx |
| `t = t1 ^ t2`（幂） | 循环乘（现有实现核对） |
| 跳转 | `cmp` + `jcc`（jne/je/jg/jge/jl/jle） |
| `print t` | `call print_int_i`（参数 eax） |
| `scan` | `call read_int_i` |
| `a[i]` | 地址 = base + i*4 → `mov reg, [addr]` |
| `*p` | 间接访存 |
| `&x` | `lea reg, [ebp-off]` |
| `PARAM x`（临时变量） | `push <x 所在寄存器>` |
| `PARAM x`（常量） | `push imm` |
| `PARAM x`（变量） | `push dword [ebp-off]` |
| `CALL f, n` | `call label_f` + `add esp, n*4`（调用者清栈）；返回值立即 `r := eax` 暂存（防递归/嵌套破坏 eax） |
| `RETURN e` | `mov eax, e; jmp <func>_end` |
| `RETURN`（void） | `jmp <func>_end` |
| `SCAN x` | `call read_int_i; mov [ebp-off], eax` |
| `FUNC_LABEL f, size` | `push ebp; mov ebp,esp; sub esp,size`（size 由中间代码回填，多函数/递归复用） |
| `FUNC_END f` | `<label>_end: mov esp,ebp; pop ebp; ret`（main 额外 `mov eax,0` 保证退出码 0） |

### 7.3 函数调用约定（[已实现] 32 位 cdecl）
```
调用方：PARAM 逆序压栈 → CALL → 清理栈（add esp, n*4）
被调方：push ebp; mov ebp,esp; 形参在 [ebp+8],[ebp+12]…（正偏移）
        局部变量 [ebp-4],…（负偏移，栈向下生长）
        返回值放 eax; leave; ret
外部 printf/scanf 交互遵循同一约定
```
实现要点（阶段 5）：
- `FUNC_LABEL/FUNC_END` 使序言/尾声逐函数统一生成（替换原硬编码 main 序言），支持多函数与递归
- 实参链按文法 `Args: Args COMMA Exp` 左结合递归展开（阶段 5 修复：尾部为裸表达式时直接求值，不再丢失多实参）
- 指针变量分配独立栈槽（修复原 `-1` 野指针偏移与 `setSymOffset` 共享槽位 hack，见 §0 D 类补充）
- 数组/指针地址计算见 `isVarIndex` / `genArrayAddrIntoEdx`（变量索引 `sub edx,ecx` 适配栈向下生长）

### 7.4 输出
- `AsmCode` 按「数据段 + 代码段」组织字符串，最终写 `asm/test.asm`
- 文件头部固定 `%include "asm/aso_io.inc"`（已实现，勿再污染 `asm_io.asm`）

## 8. 代码优化（[已实现] 1 分）

### 8.1 常量折叠
- 四元式级：`t := c1 op c2`（c1、c2 均为常量，op ∈ +−*/%^）→ 直接计算 → `t := c`
- 除零/模零不折叠；`^` 指数 <1 不折叠（汇编 `pow_i_i` 对指数 0 语义特殊）
- 例：`a = 3 + 4;` → `t := 3 ADD 4` → `t := 7`
- 汇编层配合：`t := c`（临时变量常量赋值）直接 `mov reg, c`，不再落内存

### 8.2 死代码消除
- def-use 分析（use 为包含匹配：`a[t0]`/`&a`/`*p` 内嵌引用均识别）
- 结果变量（含临时变量）后续无引用的赋值/运算删除；迭代至稳定
- 副作用写目标（`*p := v`、`a[i] := v`）不删除，且其符号名内嵌变量计入 use
- 仅统计可达指令的 use（不可达区不产生伪 use）

### 8.3 不可达代码删除
- 从每个 `FUNC_LABEL` 入口做可达性分析（顺序推进 + 跳转目标 + 条件跳转 fall-through）
- `RETURN`/`JUMP` 为终结指令，其后未被任何跳转引用的指令删除
- 函数边界（`FUNC_LABEL`/`FUNC_END`）与跳转目标指令永不删除

### 8.4 跳转目标重映射
- 删除四元式后，维护旧索引→新索引映射，修复所有 `JUMP` 系列四元式的 `result.target`（行号）

### 8.5 实现位置与验收
- `InterCode::optimize()`（`interCode.cpp`），在 `Root_Generate()` 生成后、打印与汇编生成前调用
- 验收：`test_intercode/T6-1~4`（折叠/死代码/调用死代码/不可达）；expect 支持 `!` 前缀断言「不存在」

## 9. 错误处理（[已实现] 1 分）

### 9.1 错误分级与来源
| 级别 | 来源 | 处理 |
|---|---|---|
| 词法错误 | scanner | 记录、继续扫描 |
| 语法错误 | parser | 记录、同步恢复（error 产生式）、继续分析 |
| 语义错误 | 类型检查/符号表 | 记录、跳过该声明/语句、继续 |
| 警告 | 未使用变量检查 | 记录、**不阻断编译**（退出码仍为 0） |

### 9.2 统一错误报告模块（`error_report/`，阶段 7 新增）
- 所有阶段错误经 `error_report.h` 集中收集，输出统一格式（阶段 + 行号 + 列号）：
```
词法错误 第 3 行 第 5 列: 非法字符 '#'
语法错误 第 5 行 第 30 列: syntax error, unexpected '}', expecting SEMI
[语义错误] 第 8 行: 变量 'x' 未声明
[警告] 第 2 行: 变量 'unused' 已声明但从未使用
```
- 列号来源：scanner.l 用 `YY_USER_ACTION` 维护 `lex_col`（扫描游标）与 `lex_tok_col`（当前 token 起始列），`lexCurrentCol()` 供 yyerror 取用
- 编译结束输出分级统计摘要（**措辞避开 "X错误" 连续子串**，避免与词法/语法/语义测试的计数与否定断言互相干扰）：
```
错误统计: 词法0 语法1 语义2 | 警告1 | 共3个
```

### 9.3 未使用变量检查（分级示例：警告）
- `VarSym` 新增 `used` / `isParam` 标志；ID_Exp / 数组元素 / `&id` / `*id` / scanf 目标处标记 `used`
- `popScope` 弹出作用域时，对 `!used && !isParam` 的变量报告警告（函数形参豁免，避免误报）
- 作用域弹出顺序：函数体结束 → 函数作用域 → 全局作用域，各层独立检查

### 9.4 统计与退出码
- `printErrorSummary()`：存在错误或警告时才输出摘要
- 退出码：`--lex` / `--parse-only` / 完整编译均由错误是否存在决定（警告不改变退出码）
- 不崩溃原则：词法/语法错误均继续分析（语法错误 ≥20 条才终止）；存在错误时不生成中间代码/汇编
