# 编译器测试用例

> 测试分层：**单元测试（符号表/中间代码）→ 分阶段测试（词法/语法/语义）→ 集成测试（编译→运行）→ 回归**。
> 每个用例标注：编号、输入、期望输出。实现阶段按编号逐个认领并执行。
> 现有 `test_code/test1~6.c` 为运行回归基线（T0-2 必须先全绿）。

## 2. 词法测试（阶段 1）

### 2.1 合法输入（对照《词法分析器上机要求》样例格式）

| 编号 | 输入片段 | 期望 token 序列 |
|---|---|---|
| L1 | `void main() {` | `VOID IDENTIFIER(main) ( ) {` |
| L2 | `int a = 0;` | `INT IDENTIFIER(a) ASSIGN_OP CONST(0) SEMI` |
| L3 | `a + b * (c - 1) ^ 2` | `ID ADD ID MUL ( ID SUB CONST ) POW CONST` |
| L4 | `a == b && !c \|\| d >= e` | `ID EQ_OP ID AND NOT ID OR ID GE_OP ID` |
| L5 | `a[2] = *p;` | `ID [ CONST ] ASSIGN_OP MUL ID SEMI` |
| L6 | `// 注释\n/* 块注释 */\nint x;` | 注释被跳过，仅 `INT IDENTIFIER(x) SEMI` |
| L7 | `for (int i = 0; i < 3; )` | `FOR ( INT ID SEMI ID LT CONST SEMI )` |

### 2.2 非法输入（期望词法错误）

| 编号 | 输入 | 期望 |
|---|---|---|
| L8 | `int a = @;` | 第 1 行：非法字符 `@`，继续扫描 |
| L9 | `int a = 12abc;` | `12abc` 拆为 `CONST(12)` + `IDENTIFIER(abc)` 或报错（实现时明确策略） |
| L10 | `/* 未闭合注释` | 文件尾：未闭合注释错误 |
| L11 | `int 999 = 1;` | `999` 后紧跟 `=`，语法层报错（词法正确产出 CONST） |
| L12 | `a = 2147483648;` | 整型溢出提示（或按 long 处理，实现时明确） |

## 3. 语法测试（阶段 2）

### 3.1 合法程序（期望：分析通过、AST 正确）

| 编号 | 程序要点 | 期望 |
|---|---|---|
| S1 | `int main(){ }` | 空函数体合法 |
| S2 | `int main(){ int a=1,b=2; a=b; }` | 多变量声明、赋值 |
| S3 | `if(a>b) x=1; else x=2;` | if-else |
| S4 | `if(a) x=1; if(b) y=2; else z=3;` | 悬空 else 绑定最近 if |
| S5 | `while(a<10){ a=a+1; }` | while + 复合语句 |
| S6 | `for(;;){ break; }` | 空表达式 for、break |
| S7 | `for(int i=0;i<5;i=i+1){ if(i==2) continue; }` | for 初始化、continue |
| S8 | `int f(int x){ return x+1; }` | 函数定义（加分项） |
| S9 | `return;`（void 函数内） | return 无表达式 |

### 3.2 非法程序（期望：语法错误 + 恢复后继续报后续错误）

| 编号 | 输入 | 期望错误 |
|---|---|---|
| S10 | `int main( { }` | 期望 `)`（近 "{"） |
| S11 | `a = 1 + ;` | 期望表达式（近 ";"），且在 `;` 后恢复 |
| S12 | `while(a<10 { a=1; }` | 期望 `)`，恢复后不再误报 |
| S13 | `int 1x = 3;` | 词法产出 CONST(1)+ID(x)，语法期望 IDENTIFIER 报错 |
| S14 | 连续多个语法错误 | 一次编译报出多个错误（错误恢复验证） |

## 4. 语义测试：类型检查（阶段 3）

| 编号 | 输入（片段） | 期望错误（带行号） |
|---|---|---|
| C1 | `int main(){ x = 1; }` | 变量 `x` 未声明 |
| C2 | `int main(){ int a; int a; }` | 变量 `a` 重复定义（同作用域） |
| C3 | `int main(){ int a; int *p; p = a; }` | 赋值类型不兼容（int* ← int） |
| C4 | `int main(){ int *p; *p = 1; }` | 无（`*p` 解引用指针，合法）；若 p 未初始化赋值则另报（实现时明确是否检查） |
| C5 | `int main(){ int a; a[0] = 1; }` | 下标操作数不是数组/指针 |
| C6 | `int main(){ int a[3]; a = 1; }` | 不能给数组名赋值 |
| C7 | `int f(){ return; }`（返回 int） | 返回值类型不匹配 |
| C8 | `int main(){ int a = 1; if(a) x=1; }` | 条件合法；x 未声明（顺序检查） |
| C9 | `void f(int a); int main(){ f(); }` | 实参个数不匹配 |
| C10 | `int main(){ int a; a / 0; }` | 常量除零（优化期） |
| C11 | `int main(){ int a,b; a = b + ; }` | 语法错误（不属于语义，验证分层） |

## 5. 中间代码测试（阶段 4）

| 编号 | C 片段 | 期望四元式（关键部分） |
|---|---|---|
| Q1 | `a = 1 + 2;` | `t1=1; t2=2; t=t1+t2; a=t`（优化后可为 `a=3`） |
| Q2 | `if(a>b) x=1; else y=2;` | `JUMP_LE L1; x=1; JUMP L2; L1: y=2; L2:` |
| Q3 | `while(a<10){a=a+1;}` | `L1: JUMP_GE L2; a=a+1; JUMP L1; L2:` |
| Q4 | `a==b && c<d` | 短路：`a==b 假→跳; c<d 假→跳`（回填真值链） |
| Q5 | `print_int(a+1);` | `t=a+1; PRINT t` |
| Q6 | `for(i=0;i<5;i=i+1){}` | 初始化/条件/步进三段 + 回填 |

## 8. 集成与回归（阶段 8）

### 8.1 端到端脚本回归
```bash
for f in test_code/test*.c; do
  ./build/scanner_parser_test "$f"
  nasm -f elf32 -d ELF_TYPE -i . asm/test.asm -o build/test.o
  gcc -m32 -no-pie build/test.o asm/asm_io.o -o build/test
  out=$(./build/test); [ "$out" = "期望值" ] && echo "PASS $f" || echo "FAIL $f: $out"
done
```
